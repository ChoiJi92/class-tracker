# 수업 관리 트래커

카카오톡 대화 파일을 업로드하면 수업 시작/종료 메시지를 자동으로 파싱하여 수업 기록을 정리하고, 엑셀 파일로 다운로드할 수 있는 웹 애플리케이션입니다.

## 주요 기능

- **카카오톡 대화 파싱** - PC(.txt/.csv) 및 모바일(.txt) 내보내기 파일 모두 지원
- **학생 관리** - 학생 이름/별명 등록, localStorage에 저장되어 재방문 시 유지
- **자동 매칭** - 수업 시작/종료 키워드와 학생 이름을 자동으로 매칭 (띄어쓰기 무시)
- **미분류 처리** - 자동 매칭 실패 시 학생 이름 후보를 표시하고, 클릭 한 번으로 학생 등록
- **월별 필터** - 특정 월의 수업 기록만 선택하여 분석
- **엑셀 다운로드** - 지도사명, 이용자명, 활동 횟수, 활동일자(시간) 형식의 엑셀 파일 생성

## 사용 방법

1. 웹사이트 접속
2. 학생 이름 등록 (최초 1회, 이후 자동 저장)
3. 카카오톡 대화 내보내기 파일(.txt/.csv) 업로드
4. 월 선택 → 결과 확인 → 미분류 메시지 처리
5. "엑셀 다운로드" 클릭

### 카카오톡 대화 내보내기 방법

- **PC**: 채팅방에서 `Ctrl+S` → .txt/.csv 파일 저장
- **모바일(iPhone)**: 채팅방 → ≡ → 설정 → 대화 내보내기 → 텍스트 메시지만 보내기

## 기술 스택

- React + TypeScript (Vite)
- Tailwind CSS
- SheetJS (xlsx) - 브라우저에서 엑셀 생성
- Vercel 배포

## 로컬 실행

```bash
npm install
npm run dev
```
